# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE: 12.11.2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
## STEP 1:
Setup Workspace:  
Open Autodesk Fusion 360, create a new design, and set the document 
units to millimeters (mm). 
## STEP 2: Sketch Base Flange: 
Select the Top (XY) plane, click Create Sketch, and draw the outer 
base profile (100 mm total length, 76 mm total width)

flange upward by 15 mm.

## STEP 4:Create Central Boss: 
Create a new sketch on the top face of the base flange, draw a
